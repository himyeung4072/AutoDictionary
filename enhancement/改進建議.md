# 默書神器 - 改進建議報告

## 整體評估

這是一個功能完整的語音朗讀工具，代碼結構清晰，已有不錯的基礎。以下是詳細的分析和改進建議。

---

## 1. 功能面改進

### 現有問題

- 沒有進度指示器（用戶不知道整體進度）
- 缺少詞語/句子隨機播放功能
- 無法調整音量和音調
- 沒有鍵盤快捷鍵支援

### 建議新增功能

```javascript
// 進度條顯示
// 隨機播放模式
// 音量/音調控制
// 快捷鍵：空白鍵暫停、Esc取消
```

// 建議加入更完整的錯誤處理

### 鍵盤快捷鍵

```javascript
document.addEventListener('keydown', (e) => {
    // 避免在輸入框中觸發
    if (e.target.tagName === 'TEXTAREA' || e.target.tagName === 'INPUT') {
        return;
    }
    
    switch(e.key) {
        case ' ':  // 空白鍵：暫停/恢復
            e.preventDefault();
            if (!document.getElementById('pauseBtn').disabled) {
                togglePause();
            }
            break;
        case 'Escape':  // Esc：取消
            if (!document.getElementById('stopBtn').disabled) {
                stopReading();
            }
            break;
        case 'Enter':  // Enter：開始
            if (!document.getElementById('startBtn').disabled) {
                startReading();
            }
            break;
    }
});
```

## 8. 匯入/匯出功能

```javascript
// 匯出詞表
function exportWordList() {
    const text = document.getElementById('words').value;
    const blob = new Blob([text], { type: 'text/plain;charset=utf-8' });
    const url = URL.createObjectURL(blob);
    const a = document.createElement('a');
    a.href = url;
    a.download = '詞表.txt';
    a.click();
    URL.revokeObjectURL(url);
}

// 匯入詞表
function importWordList(file) {
    const reader = new FileReader();
    reader.onload = (e) => {
        document.getElementById('words').value = e.target.result;
        saveSettings();
    };
    reader.readAsText(file);
}

// HTML
<div class="import-export">
    <button onclick="exportWordList()" class="btn-secondary">匯出詞表</button>
    <label class="btn-secondary">
        匯入詞表
        <input type="file" accept=".txt" onchange="importWordList(this.files[0])" hidden>
    </label>
</div>
```
