# 英文朗讀問題分析報告

## 問題描述

在使用「默書神器」朗讀英語時，發現以下兩個問題：

### 問題 1：所有格撇號被錯誤處理

**現象**：朗讀 `Reach's` 時，會先讀 `Reach'`，之後才讀 `s`

**範例文本**：
```
Reach's approach, is to go deep — Transforming lives with intensive reading curriculum.
```

**實際朗讀結果**：
```
Reach ... left single quote s approach ...
```

### 問題 2：英文標點符號不會朗讀

**現象**：`,`（逗號）、`—`（破折號）、`.`（句號）這些英文標點符號不會被朗讀出來

---

## 問題根源分析

### 現有程式碼（第 3671-3717 行）

```javascript
function convertPunctuationToSpeech(text, lang) {
    const pauseMark = '...';
    
    if (!lang.startsWith('zh')) {
        // 英文標點符號轉換 - 在標點前加入停頓
        return text
            .replace(/，/g, pauseMark + ' comma ')
            .replace(/。/g, pauseMark + ' period ')
            // ... 其他中文標點
            .replace(/'/g, pauseMark + ' left single quote ')
            .replace(/'/g, pauseMark + ' right single quote ')
            // ...
    }
}
```

### 問題 1 根源：撇號處理不當

現有程式碼將 `'`（右單引號/撇號）統一替換為 `... left single quote`，但這會錯誤處理：

| 情境 | 原文 | 錯誤轉換結果 |
|------|------|--------------|
| 所有格 | `Reach's` | `Reach... left single quote s` |
| 縮寫 | `don't` | `don... left single quote t` |
| 縮寫 | `I'm` | `I... left single quote m` |

**關鍵問題**：程式碼沒有區分「所有格/縮寫中的撇號」和「引號」。

### 問題 2 根源：只處理中文標點

現有程式碼在英文模式下只轉換**中文標點符號**（全形），完全沒有處理**英文標點符號**（半形）：

| 標點類型 | 中文（已處理） | 英文（未處理） |
|----------|----------------|----------------|
| 逗號 | `，` ✅ | `,` ❌ |
| 句號 | `。` ✅ | `.` ❌ |
| 破折號 | — | `—` ❌ |
| 問號 | `？` ✅ | `?` ❌ |
| 驚嘆號 | `！` ✅ | `!` ❌ |

---

## Web Speech API 技術背景

### SpeechSynthesisUtterance 的標點處理

根據 [Web Speech API 文件](https://context7.com/webaudio/web-speech-api/llms.txt)，`SpeechSynthesisUtterance` 會：

1. **自動處理標點停頓**：遇到 `.`、`,`、`?` 等會自然停頓
2. **不會朗讀標點名稱**：標點符號本身不會被讀出來
3. **支援 SSML**（部分瀏覽器）：可使用 `<break>` 標籤控制停頓

### SSML 停頓控制

```xml
<speak>
  Hello <break time="500ms"/> World
</speak>
```

但 **Web Speech API 對 SSML 的支援有限**，不同瀏覽器實作不一致，因此我們採用文字替換方案。

## 解決方案

### 方案設計原則

1. **保護所有格和縮寫**：`'s`、`'t`、`'re`、`'ve`、`'ll`、`'d`、`'m` 不應被轉換
2. **處理英文半形標點**：`,`、`.`、`!`、`?`、`;`、`:`、`—`、`–`
3. **智慧句號處理**：區分句尾句號和縮寫（如 `Dr.`、`Mr.`）
4. **保持停頓效果**：使用 `...` 作為停頓標記

### 需要處理的英文標點符號

| 標點 | 名稱 | Unicode | 朗讀文字 |
|------|------|---------|----------|
| `,` | 逗號 | U+002C | comma |
| `.` | 句號 | U+002E | period |
| `!` | 驚嘆號 | U+0021 | exclamation mark |
| `?` | 問號 | U+003F | question mark |
| `;` | 分號 | U+003B | semicolon |
| `:` | 冒號 | U+003A | colon |
| `—` | 長破折號 | U+2014 | dash |
| `–` | 短破折號 | U+2013 | dash |
| `"` | 左雙引號 | U+201C | quote |
| `"` | 右雙引號 | U+201D | end quote |
| `'` | 左單引號 | U+2018 | quote |
| `'` | 右單引號 | U+2019 | （需特殊處理） |

### 所有格/縮寫模式

需要保護的常見縮寫模式：

```javascript
// 所有格
word's → word's（不轉換）

// 常見縮寫
don't, won't, can't, isn't, aren't, wasn't, weren't
I'm, you're, we're, they're, he's, she's, it's
I've, you've, we've, they've
I'll, you'll, we'll, they'll, he'll, she'll
I'd, you'd, we'd, they'd, he'd, she'd
```

### 句號的特殊處理

需要排除的縮寫：

```javascript
// 常見英文縮寫（句號不應朗讀）
Mr., Mrs., Ms., Dr., Prof., Jr., Sr.
Inc., Ltd., Corp., Co.
etc., e.g., i.e., vs., a.m., p.m.
U.S., U.K., U.N.
```

## 建議的程式碼修改

### 修改後的 `convertPunctuationToSpeech` 函數

```javascript
function convertPunctuationToSpeech(text, lang) {
    const pauseMark = '...';
    
    if (!lang.startsWith('zh')) {
        // === 英文標點符號處理 ===
        
        // 步驟 1：保護所有格和縮寫中的撇號
        // 匹配 word's, don't, I'm, you're, we've, they'll, he'd 等
        let result = text.replace(/(\w)'(\w)/g, '$1\u0000APOSTROPHE\u0000$2');
        
        // 步驟 2：保護常見縮寫的句號
        const abbreviations = [
            'Mr', 'Mrs', 'Ms', 'Dr', 'Prof', 'Jr', 'Sr',
            'Inc', 'Ltd', 'Corp', 'Co',
            'etc', 'e\\.g', 'i\\.e', 'vs', 'a\\.m', 'p\\.m',
            'U\\.S', 'U\\.K', 'U\\.N'
        ];
        abbreviations.forEach(abbr => {
            const regex = new RegExp(`\\b(${abbr})\\.`, 'gi');
            result = result.replace(regex, '$1\u0000ABBRDOT\u0000');
        });
        
        // 步驟 3：保護小數點（數字.數字）
        result = result.replace(/(\d)\.(\d)/g, '$1\u0000DECIMAL\u0000$2');
        
        // 步驟 4：轉換英文標點符號（半形）
        result = result
            // 英文標點（半形）
            .replace(/,/g, pauseMark + ' comma ')
            .replace(/\./g, pauseMark + ' period ')
            .replace(/!/g, pauseMark + ' exclamation mark ')
            .replace(/\?/g, pauseMark + ' question mark ')
            .replace(/;/g, pauseMark + ' semicolon ')
            .replace(/:/g, pauseMark + ' colon ')
            .replace(/—/g, pauseMark + ' dash ')      // em dash
            .replace(/–/g, pauseMark + ' dash ')      // en dash
            // 中文標點（全形）- 保留原有處理
            .replace(/，/g, pauseMark + ' comma ')
            .replace(/。/g, pauseMark + ' period ')
            .replace(/！/g, pauseMark + ' exclamation mark ')
            .replace(/？/g, pauseMark + ' question mark ')
            .replace(/；/g, pauseMark + ' semicolon ')
            .replace(/：/g, pauseMark + ' colon ')
            .replace(/、/g, pauseMark + ' pause ')
            // 引號處理（排除已保護的撇號）
            .replace(/"/g, pauseMark + ' quote ')
            .replace(/"/g, pauseMark + ' end quote ')
            .replace(/'/g, pauseMark + ' quote ')
            .replace(/'/g, pauseMark + ' end quote ')
            .replace(/「/g, pauseMark + ' quote ')
            .replace(/」/g, pauseMark + ' end quote ')
            // 括號
            .replace(/（/g, pauseMark + ' left parenthesis ')
            .replace(/）/g, pauseMark + ' right parenthesis ')
            .replace(/\(/g, pauseMark + ' left parenthesis ')
            .replace(/\)/g, pauseMark + ' right parenthesis ');
        
        // 步驟 5：還原保護的字元
        result = result
            .replace(/\u0000APOSTROPHE\u0000/g, "'")
            .replace(/\u0000ABBRDOT\u0000/g, ".")
            .replace(/\u0000DECIMAL\u0000/g, ".");
        
        return result;
    } else {
        // 中文標點符號轉換（保持原有邏輯）
        return text
            .replace(/，/g, pauseMark + ' 逗號 ')
            .replace(/。/g, pauseMark + ' 句號 ')
            .replace(/！/g, pauseMark + ' 感嘆號 ')
            .replace(/？/g, pauseMark + ' 問號 ')
            .replace(/；/g, pauseMark + ' 分號 ')
            .replace(/：/g, pauseMark + ' 冒號 ')
            .replace(/、/g, pauseMark + ' 頓號 ')
            .replace(/"/g, pauseMark + ' 左引號 ')
            .replace(/"/g, pauseMark + ' 右引號 ')
            .replace(/'/g, pauseMark + ' 左單引號 ')
            .replace(/'/g, pauseMark + ' 右單引號 ')
            .replace(/「/g, pauseMark + ' 左引號 ')
            .replace(/」/g, pauseMark + ' 右引號 ')
            .replace(/（/g, pauseMark + ' 左括號 ')
            .replace(/）/g, pauseMark + ' 右括號 ')
            .replace(/\(/g, pauseMark + ' 左括號 ')
            .replace(/\)/g, pauseMark + ' 右括號 ');
    }
}
```

## 實作注意事項

1. **使用 NULL 字元作為佔位符**：`\u0000` 不會出現在正常文本中，安全用於臨時標記
2. **處理順序很重要**：必須先保護特殊情況，再進行替換，最後還原
3. **正則表達式效能**：多次 replace 可能影響效能，但對於短文本影響不大
4. **瀏覽器相容性**：此方案不依賴 SSML，所有支援 Web Speech API 的瀏覽器都適用

## 結論

現有程式碼的問題在於：
1. 沒有區分「所有格/縮寫撇號」和「引號」
2. 只處理中文標點，忽略英文標點

建議的解決方案採用「保護-替換-還原」三步驟策略，能夠正確處理各種英文文本情境，同時保持與現有中文處理邏輯的相容性。
