## 1. 專案概述

### 1.1 產品定位

「默書神器」是一款專為中小學生設計的默書練習工具，透過語音合成技術朗讀詞語或文章，讓學生可以獨立進行默書練習。

### 1.2 目標用戶

- 香港中小學生（主要）
- 中國大陸學生
- 學習中文/英文的學生
- 家長和教師

### 1.3 核心價值

| 價值點 | 說明 |
|--------|------|
| 自主學習 | 學生可獨立練習，無需家長陪同 |
| 多語言支援 | 粵語、普通話、英語三種語言 |
| 靈活設定 | 可調整速度、重複次數、間隔時間 |
| 離線使用 | 純前端應用，無需網絡連接 |

### 1.4 技術棧（現有）

- **前端框架**：純 HTML5 + CSS3 + Vanilla JavaScript
- **語音技術**：Web Speech API (SpeechSynthesis)
- **資料存儲**：localStorage
- **樣式方案**：CSS Custom Properties + Media Queries

## 2. 功能需求規格

### 2.1 朗讀模式

#### 2.1.1 詞語/句子模式 (Word Mode)

```
輸入格式：每行一個詞語或句子
範例：
蘋果
香蕉
今天天氣很好
```

**朗讀流程：**
1. 按行分割文字
2. 過濾空行
3. 依序朗讀每個詞語
4. 每個詞語可重複 N 次（1-10 次）
5. 每次朗讀後等待書寫時間

**計算公式：**
```
等待時間 = 每字書寫時間(秒) × 1000 (毫秒)
```

#### 2.1.2 文章模式 (Article Mode)

```
輸入格式：連續文章，在標點符號處分割
範例：
今天天氣很好。我們一起去公園玩吧！
```

**分割邏輯 (splitArticleSegments)：**
```javascript
// 標點符號正則表達式
const PUNCTUATION_PATTERN = /[。！？；，、．.!?;,：:「」""''（）\(\)—–…－\-《》·]/;

// 分割結果格式
[
  { type: 'text', content: '今天天氣很好' },
  { type: 'punct', content: '。' },
  { type: 'text', content: '我們一起去公園玩吧' },
  { type: 'punct', content: '！' }
]
```

**朗讀流程：**
1. 使用 `splitArticleSegments()` 分割文章
2. 依序處理每個 segment
3. 文字段落：朗讀 N 次（可設定）
4. 標點符號：朗讀 1 次（固定）
5. 每個 segment 後加入停頓

**等待時間計算：**
```javascript
// 中文：按字數計算
function calculateWaitTime(sentence, lang) {
  if (lang.startsWith('zh')) {
    const charCount = (sentence.match(/[\u4e00-\u9fff]/g) || []).length;
    return charCount * charWaitTime * 1000;
  } else {
    // 英文：按單詞數計算
    const wordCount = sentence.split(/\s+/).filter(w => w.length > 0).length;
    return wordCount * charWaitTime * 1000;
  }
}
```

### 4.2 ManualReadingState 模組

管理手動朗讀模式的狀態。

#### 4.2.1 完整實作

```javascript
const ManualReadingState = {
  readingMode: 'auto',
  currentIndex: -1,
  hasStarted: false,
  isReading: false,
  items: [],
  totalItems: 0,
  
  reset() {
    this.currentIndex = -1;
    this.hasStarted = false;
    this.isReading = false;
    this.items = [];
    this.totalItems = 0;
  },
  
  initItems(text, mode, punctuationReadingEnabled) {
    if (mode === 'word') {
      this.items = text.split('\n')
        .map(s => s.trim())
        .filter(s => s !== '')
        .map(s => ({ type: 'text', content: s }));
    } else {
      const segments = splitArticleSegments(text);
      this.items = punctuationReadingEnabled 
        ? segments 
        : segments.filter(s => s.type === 'text');
    }
    this.totalItems = this.items.length;
    return this.items;
  },
  
  getCurrentItem() {
    if (this.currentIndex >= 0 && this.currentIndex < this.items.length) {
      return this.items[this.currentIndex];
    }
    return null;
  },
  
  moveNext() {
    if (this.currentIndex < this.items.length - 1) {
      this.currentIndex++;
      return true;
    }
    return false;
  },
  
  movePrevious() {
    if (this.currentIndex > 0) {
      this.currentIndex--;
      return true;
    }
    return false;
  },
  
  isAtFirst() { return this.currentIndex <= 0; },
  isAtLast() { return this.currentIndex >= this.items.length - 1; }
};
```

### 4.3 文字分割模組

#### 4.3.1 splitArticleSegments 函數

```javascript
function splitArticleSegments(text) {
  // 邊界檢查
  if (text === null || text === undefined || text === '') {
    return [];
  }
  
  const segments = [];
  let currentText = '';
  let currentPunct = '';
  
  for (let i = 0; i < text.length; i++) {
    const char = text[i];
    
    if (PUNCTUATION_PATTERN.test(char)) {
      // 保存累積的文字
      if (currentText.length > 0) {
        segments.push({ type: 'text', content: currentText });
        currentText = '';
      }
      
      // 合併連續相同標點（如 …… 或 ——）
      if (currentPunct.length > 0 && currentPunct[0] === char) {
        currentPunct += char;
      } else {
        if (currentPunct.length > 0) {
          segments.push({ type: 'punct', content: currentPunct });
        }
        currentPunct = char;
      }
    } else {
      // 保存累積的標點
      if (currentPunct.length > 0) {
        segments.push({ type: 'punct', content: currentPunct });
        currentPunct = '';
      }
      currentText += char;
    }
  }
  
  // 處理結尾
  if (currentPunct.length > 0) {
    segments.push({ type: 'punct', content: currentPunct });
  }
  if (currentText.length > 0) {
    segments.push({ type: 'text', content: currentText });
  }
  
  return segments;
}
```

### 4.4 語音合成模組

#### 4.4.1 speakPromise 函數

```javascript
function speakPromise(text, lang, voiceName, rate) {
  return new Promise((resolve) => {
    const waitForResume = () => {
      if (isStopped) { resolve(); return; }
      if (isPaused) { setTimeout(waitForResume, 200); return; }
      
      // iOS workaround: 重新獲取語音列表
      const freshVoices = synth.getVoices();
      if (freshVoices.length > 0) {
        availableVoices = freshVoices;
      }
      
      // 找到要使用的語音
      let selectedVoice = null;
      if (voiceName !== 'auto') {
        selectedVoice = availableVoices.find(v => v.name === voiceName);
      }
      if (!selectedVoice) {
        selectedVoice = findBestVoice(lang);
      }
      
      // 先取消所有語音
      synth.cancel();
      
      setTimeout(() => {
        // 處理標點符號
        const punctuationEnabled = document.getElementById('punctuationReadingEnabled').value === 'true';
        const speechText = punctuationEnabled ? convertPunctuationToSpeech(text, lang) : text;
        
        // 創建 utterance
        const utterance = new SpeechSynthesisUtterance(speechText);
        utterance.rate = rate;
        
        if (selectedVoice) {
          utterance.voice = selectedVoice;
          utterance.lang = selectedVoice.lang;
        } else {
          utterance.lang = lang;
        }
        
        currentUtterance = utterance;
        isSpeaking = true;
        
        utterance.onend = () => {
          currentUtterance = null;
          isSpeaking = false;
          resolve();
        };
        
        utterance.onerror = (event) => {
          currentUtterance = null;
          isSpeaking = false;
          if (event.error === 'interrupted' || event.error === 'canceled') {
            resolve();
            return;
          }
          console.error('語音合成錯誤:', event.error);
          resolve();
        };
        
        synth.speak(utterance);
      }, 50);
    };
    
    waitForResume();
  });
}
```

```javascript
function convertPunctuationToSpeech(text, lang) {
  const pauseMarkEn = ',';
  const pauseMarkZh = '...';
  
  if (!lang.startsWith('zh')) {
    // 英文處理
    let result = text;
    
    // 保護所有格和縮寫
    result = result.replace(/(\w)[''](\w)/g, '$1\u0000APO\u0000$2');
    
    // 保護常見縮寫
    const abbreviations = ['Mr', 'Mrs', 'Ms', 'Dr', 'Prof', 'etc'];
    abbreviations.forEach(abbr => {
      const regex = new RegExp(`\\b(${abbr})\\.`, 'gi');
      result = result.replace(regex, '$1\u0000DOT\u0000');
    });
    
    // 保護小數點
    result = result.replace(/(\d)\.(\d)/g, '$1\u0000DEC\u0000$2');
    
    // 轉換標點
    result = result
      .replace(/,/g, pauseMarkEn + ' comma ')
      .replace(/\./g, pauseMarkEn + ' period ')
      .replace(/!/g, pauseMarkEn + ' exclamation mark ')
      .replace(/\?/g, pauseMarkEn + ' question mark ');
    
    // 還原保護字元
    result = result
      .replace(/\u0000APO\u0000/g, "'")
      .replace(/\u0000DOT\u0000/g, ".")
      .replace(/\u0000DEC\u0000/g, ".");
    
    return result;
  } else {
    // 中文處理
    return text
      .replace(/，/g, pauseMarkZh + ' 逗號 ')
      .replace(/。/g, pauseMarkZh + ' 句號 ')
      .replace(/！/g, pauseMarkZh + ' 感嘆號 ')
      .replace(/？/g, pauseMarkZh + ' 問號 ')
      .replace(/；/g, pauseMarkZh + ' 分號 ')
      .replace(/：/g, pauseMarkZh + ' 冒號 ')
      .replace(/、/g, pauseMarkZh + ' 頓號 ');
  }
}
```

### 6.2 朗讀流程詳解

#### 6.2.1 詞語模式朗讀流程

```javascript
async function readWords(text, lang, selectedVoice) {
  const lines = text.split('\n').map(s => s.trim()).filter(s => s !== "");
  
  // 計算每個詞語的時間和進度區間
  const wordTimes = lines.map(line => calculateWordWaitTime(line, lang, charWaitTime));
  const totalTime = wordTimes.reduce((sum, t) => sum + t, 0);
  
  // 計算進度區間
  let accumulatedPercent = 0;
  const progressRanges = wordTimes.map(time => {
    const start = accumulatedPercent;
    const percent = (time / totalTime) * 100;
    accumulatedPercent += percent;
    return { start, end: accumulatedPercent, duration: time };
  });
  
  for (let lineIdx = 0; lineIdx < lines.length; lineIdx++) {
    const line = lines[lineIdx];
    if (isStopped) break;
    
    // 更新進度條
    const { start, end, duration } = progressRanges[lineIdx];
    animateProgressFromTo(start, end, duration);
    
    // 高亮當前詞語
    HighlightManager.highlightItem(lineIdx);
    
    // 重複朗讀
    for (let i = 1; i <= repeatPerLine; i++) {
      if (isStopped) break;
      
      const repeatStartTime = Date.now();
      const countdownTimer = startCountdown(waitPerRepeat, repeatStartTime);
      
      // 朗讀（支援中斷重讀）
      do {
        wasInterrupted = false;
        updateStatus(`正在朗讀：${line} (${i}/${repeatPerLine})`, '');
        await speakPromise(line, lang, selectedVoice, speechRate);
        
        while (isPaused && !isStopped) {
          await new Promise(r => setTimeout(r, 200));
        }
      } while (wasInterrupted && !isStopped);
      
      // 等待剩餘時間
      const elapsedTime = Date.now() - repeatStartTime;
      const remainingWait = Math.max(0, waitPerRepeat - elapsedTime);
      
      if (!isStopped && remainingWait > 0) {
        await waitRemaining(remainingWait, countdownTimer);
      }
    }
  }
}
```

```javascript
async function readArticle(text, lang, selectedVoice) {
  const segments = splitArticleSegments(text);
  const PUNCT_WAIT_TIME = 500;
  
  // 計算時間和進度
  const segmentTimes = segments.map(segment => {
    if (segment.type === 'text') {
      return calculateWaitTime(segment.content, lang) * sentenceRepeat;
    } else {
      return PUNCT_WAIT_TIME;
    }
  });
  
  for (let idx = 0; idx < segments.length; idx++) {
    const segment = segments[idx];
    if (isStopped) break;
    
    // 高亮當前 segment
    HighlightManager.highlightItem(idx);
    
    if (segment.type === 'text') {
      // 文字段落：可重複 N 次
      for (let i = 1; i <= sentenceRepeat; i++) {
        if (isStopped) break;
        
        do {
          wasInterrupted = false;
          await speakPromise(segment.content, lang, selectedVoice, speechRate);
          
          while (isPaused && !isStopped) {
            await new Promise(r => setTimeout(r, 200));
          }
        } while (wasInterrupted && !isStopped);
        
        // 等待書寫時間
        if (!isStopped && remainingWait > 0) {
          await waitRemaining(remainingWait, countdownTimer);
        }
      }
    } else {
      // 標點符號：只讀 1 次
      if (punctuationReadingEnabled) {
        const punctName = getPunctuationName(segment.content, lang);
        await speakPromise(punctName, lang, selectedVoice, speechRate);
      }
      
      // 標點後停頓
      if (!isStopped) {
        await wait(PUNCT_WAIT_TIME, false);
      }
    }
  }
}
```

### 6.4 進度條動畫

```javascript
function animateProgressFromTo(startPercent, endPercent, duration) {
  stopProgressAnimation();
  
  const progressFill = document.getElementById('progressFill');
  if (prefersReducedMotion) {
    progressFill.style.width = endPercent + '%';
    return;
  }
  
  progressFill.style.width = startPercent + '%';
  
  let startTime = performance.now();
  let pausedTime = 0;
  let wasPaused = false;
  
  function animate(currentTime) {
    if (isStopped) {
      stopProgressAnimation();
      return;
    }
    
    if (isPaused) {
      if (!wasPaused) {
        pausedTime = currentTime - startTime;
        wasPaused = true;
      }
      progressState.animationId = requestAnimationFrame(animate);
      return;
    }
    
    if (wasPaused) {
      startTime = currentTime - pausedTime;
      wasPaused = false;
    }
    
    const elapsed = currentTime - startTime;
    const progress = Math.min(elapsed / duration, 1);
    const currentPercent = startPercent + (endPercent - startPercent) * progress;
    
    progressFill.style.width = currentPercent + '%';
    
    if (progress < 1) {
      progressState.animationId = requestAnimationFrame(animate);
    }
  }
  
  progressState.animationId = requestAnimationFrame(animate);
}
```

```typescript
  status: 'idle',
  currentIndex: -1,
  totalItems: 0,
  items: [],
  isReading: false,
  
  start: (items) => set({
    status: 'playing',
    items,
    totalItems: items.length,
    currentIndex: 0,
  }),
  
  pause: () => set({ status: 'paused' }),
  
  resume: () => set({ status: 'playing' }),
  
  stop: () => set({
    status: 'stopped',
    currentIndex: -1,
    isReading: false,
  }),
  
  next: () => {
    const { currentIndex, totalItems } = get();
    if (currentIndex < totalItems - 1) {
      set({ currentIndex: currentIndex + 1 });
      return true;
    }
    return false;
  },
  
  previous: () => {
    const { currentIndex } = get();
    if (currentIndex > 0) {
      set({ currentIndex: currentIndex - 1 });
      return true;
    }
    return false;
  },
  
  setCurrentIndex: (index) => set({ currentIndex: index }),
  
  setIsReading: (isReading) => set({ isReading }),
  
  reset: () => set({
    status: 'idle',
    currentIndex: -1,
    totalItems: 0,
    items: [],
    isReading: false,
  }),
}));
```

### 7.5 自定義 Hooks

```typescript
// hooks/useSpeechSynthesis.ts
import { useState, useEffect, useCallback, useRef } from 'react';
import type { Language, SpeechOptions } from '@/types';
import { findBestVoice } from '@/services/speechService';

export function useSpeechSynthesis() {
  const [voices, setVoices] = useState<SpeechSynthesisVoice[]>([]);
  const [isSpeaking, setIsSpeaking] = useState(false);
  const [isPaused, setIsPaused] = useState(false);
  const utteranceRef = useRef<SpeechSynthesisUtterance | null>(null);
  const synth = window.speechSynthesis;
  
  useEffect(() => {
    const loadVoices = () => {
      const availableVoices = synth.getVoices();
      if (availableVoices.length > 0) {
        setVoices(availableVoices);
      }
    };
    
    loadVoices();
    synth.onvoiceschanged = loadVoices;
    
    return () => {
      synth.cancel();
    };
  }, []);
  
  const speak = useCallback(async (
    text: string,
    options: SpeechOptions
  ): Promise<void> => {
    return new Promise((resolve, reject) => {
      synth.cancel();
      
      const utterance = new SpeechSynthesisUtterance(text);
      utterance.rate = options.rate;
      
      const voice = options.voiceName !== 'auto'
        ? voices.find(v => v.name === options.voiceName)
        : findBestVoice(options.lang, voices);
      
      if (voice) {
        utterance.voice = voice;
        utterance.lang = voice.lang;
      } else {
        utterance.lang = options.lang;
      }
      
      utterance.onstart = () => setIsSpeaking(true);
      utterance.onend = () => {
        setIsSpeaking(false);
        resolve();
      };
      utterance.onerror = (e) => {
        setIsSpeaking(false);
        if (e.error !== 'interrupted' && e.error !== 'canceled') {
          reject(e);
        } else {
          resolve();
        }
      };
      
      utteranceRef.current = utterance;
      synth.speak(utterance);
    });
  }, [voices]);
  
  const pause = useCallback(() => {
    synth.pause();
    setIsPaused(true);
  }, []);
  
  const resume = useCallback(() => {
    synth.resume();
    setIsPaused(false);
  }, []);
  
  const cancel = useCallback(() => {
    synth.cancel();
    setIsSpeaking(false);
    setIsPaused(false);
  }, []);
  
  const getVoicesForLanguage = useCallback((lang: Language) => {
    return voices.filter(voice => {
      if (lang === 'zh-HK') {
        return voice.lang === 'yue-HK' || voice.lang.includes('yue') || voice.lang.includes('HK');
      } else if (lang === 'zh-CN') {
        return voice.lang === 'zh-CN' || (voice.lang.startsWith('zh') && !voice.lang.includes('yue') && !voice.lang.includes('TW'));
      } else {
        return voice.lang.startsWith(lang.split('-')[0]);
      }
    });
  }, [voices]);
  
  return {
    voices,
    isSpeaking,
    isPaused,
    speak,
    pause,
    resume,
    cancel,
    getVoicesForLanguage,
  };
}
```

### 7.5.1 OCR Hook 實作

```typescript
// hooks/useOCR.ts
import { useState, useCallback, useRef, useEffect } from 'react';
import { createWorker, Worker } from 'tesseract.js';
import type { OCRLanguage, OCRStatus, OCRResult, OCRProgress } from '@/types';

interface UseOCROptions {
  lang: OCRLanguage;
  onProgress?: (progress: OCRProgress) => void;
}

interface UseOCRReturn {
  // 狀態
  status: OCRStatus;
  progress: number;
  result: OCRResult | null;
  error: string | null;
  isWorkerReady: boolean;
  
  // 方法
  recognize: (image: File | string | HTMLImageElement) => Promise<OCRResult>;
  reset: () => void;
  terminate: () => Promise<void>;
}

export function useOCR({ lang, onProgress }: UseOCROptions): UseOCRReturn {
  const [status, setStatus] = useState<OCRStatus>('idle');
  const [progress, setProgress] = useState(0);
  const [result, setResult] = useState<OCRResult | null>(null);
  const [error, setError] = useState<string | null>(null);
  const [isWorkerReady, setIsWorkerReady] = useState(false);
  
  const workerRef = useRef<Worker | null>(null);
  const langRef = useRef(lang);
  
  // 初始化 Worker
  const initWorker = useCallback(async (language: OCRLanguage) => {
    try {
      setStatus('loading');
      setProgress(0);
      
      // 建立 Worker，支援多語言
      const worker = await createWorker(language, 1, {
        logger: (m) => {
          if (m.status === 'recognizing text') {
            const prog = Math.round(m.progress * 100);
            setProgress(prog);
            onProgress?.({ status: m.status, progress: prog });
          }
        },
      });
      
      workerRef.current = worker;
      langRef.current = language;
      setIsWorkerReady(true);
      setStatus('idle');
      
      return worker;
    } catch (err) {
      setError(err instanceof Error ? err.message : '初始化 OCR 失敗');
      setStatus('error');
      throw err;
    }
  }, [onProgress]);
  
  // 辨識圖片
  const recognize = useCallback(async (
    image: File | string | HTMLImageElement
  ): Promise<OCRResult> => {
    try {
      setStatus('recognizing');
      setProgress(0);
      setError(null);
      
      // 確保 Worker 已初始化且語言正確
      if (!workerRef.current || langRef.current !== lang) {
        await initWorker(lang);
      }
      
      const worker = workerRef.current!;
      const { data } = await worker.recognize(image);
      
      const ocrResult: OCRResult = {
        text: data.text.trim(),
        confidence: data.confidence,
        words: data.words?.map(w => ({
          text: w.text,
          confidence: w.confidence,
          bbox: w.bbox,
        })),
      };
      
      setResult(ocrResult);
      setStatus('success');
      setProgress(100);
      
      return ocrResult;
    } catch (err) {
      const errorMsg = err instanceof Error ? err.message : '辨識失敗';
      setError(errorMsg);
      setStatus('error');
      throw err;
    }
  }, [lang, initWorker]);
  
  // 重置狀態
  const reset = useCallback(() => {
    setStatus('idle');
    setProgress(0);
    setResult(null);
    setError(null);
  }, []);
  
  // 終止 Worker
  const terminate = useCallback(async () => {
    if (workerRef.current) {
      await workerRef.current.terminate();
      workerRef.current = null;
      setIsWorkerReady(false);
    }
  }, []);
  
  // 清理
  useEffect(() => {
    return () => {
      workerRef.current?.terminate();
    };
  }, []);
  
  return {
    status,
    progress,
    result,
    error,
    isWorkerReady,
    recognize,
    reset,
    terminate,
  };
}
```

### 7.5.2 相機 Hook 實作

```typescript
// hooks/useCamera.ts
import { useState, useCallback, useRef } from 'react';

interface UseCameraReturn {
  // 狀態
  isOpen: boolean;
  stream: MediaStream | null;
  error: string | null;
  
  // 方法
  openCamera: () => Promise<void>;
  closeCamera: () => void;
  capturePhoto: () => Promise<File | null>;
}

export function useCamera(): UseCameraReturn {
  const [isOpen, setIsOpen] = useState(false);
  const [stream, setStream] = useState<MediaStream | null>(null);
  const [error, setError] = useState<string | null>(null);
  
  const videoRef = useRef<HTMLVideoElement | null>(null);
  
  const openCamera = useCallback(async () => {
    try {
      setError(null);
      
      const mediaStream = await navigator.mediaDevices.getUserMedia({
        video: {
          facingMode: 'environment', // 使用後置鏡頭
          width: { ideal: 1920 },
          height: { ideal: 1080 },
        },
      });
      
      setStream(mediaStream);
      setIsOpen(true);
    } catch (err) {
      const errorMsg = err instanceof Error ? err.message : '無法開啟相機';
      setError(errorMsg);
      throw err;
    }
  }, []);
  
  const closeCamera = useCallback(() => {
    if (stream) {
      stream.getTracks().forEach(track => track.stop());
      setStream(null);
    }
    setIsOpen(false);
  }, [stream]);
  
  const capturePhoto = useCallback(async (): Promise<File | null> => {
    if (!videoRef.current || !stream) return null;
    
    const video = videoRef.current;
    const canvas = document.createElement('canvas');
    canvas.width = video.videoWidth;
    canvas.height = video.videoHeight;
    
    const ctx = canvas.getContext('2d');
    if (!ctx) return null;
    
    ctx.drawImage(video, 0, 0);
    
    return new Promise((resolve) => {
      canvas.toBlob((blob) => {
        if (blob) {
          const file = new File([blob], `capture-${Date.now()}.jpg`, {
            type: 'image/jpeg',
          });
          resolve(file);
        } else {
          resolve(null);
        }
      }, 'image/jpeg', 0.9);
    });
  }, [stream]);
  
  return {
    isOpen,
    stream,
    error,
    openCamera,
    closeCamera,
    capturePhoto,
  };
}
```

```typescript
  disabled = false,
  onClick,
  className,
```

```typescript
// 智能功能設計
interface SmartFeatures {
  // 1. 自動檢測語言
  autoDetectLanguage: (text: string) => Language;
  
  // 2. 自動檢測模式（詞語 vs 文章）
  autoDetectMode: (text: string) => TextMode;
  
  // 3. 智能時間估算
  estimateDuration: (text: string, settings: Settings) => number;
  
  // 4. 難度評估
  assessDifficulty: (text: string) => 'easy' | 'medium' | 'hard';
}

// 範例：自動檢測邏輯
function autoDetectMode(text: string): TextMode {
  const lines = text.split('\n').filter(l => l.trim());
  const avgLineLength = lines.reduce((sum, l) => sum + l.length, 0) / lines.length;
  
  // 平均每行 < 10 字 → 詞語模式
  // 平均每行 >= 10 字 → 文章模式
  return avgLineLength < 10 ? 'word' : 'article';
}
```

### 12.1 選定方案：Web Speech API

本專案決定使用 **Web Speech API** 作為文字轉語音技術，這是瀏覽器原生支援的語音合成 API。

#### 12.1.1 選擇理由

| 🔒 隱私友善 | 文字不上傳到雲端 |
| ⚡ 低延遲 | 即時朗讀，無網絡延遲 |

| 🗣️ 普通話支援 | iOS/macOS 有「婷婷」優質語音 |
| 🌐 瀏覽器原生 | 無需後端伺服器，純前端實作 |

### 12.3 Web Speech API 實作細節

#### 12.3.1 核心 Hook 設計

```typescript
// hooks/useSpeechSynthesis.ts
import { useState, useEffect, useCallback, useRef } from 'react';

interface SpeechOptions {
  lang: 'zh-HK' | 'zh-CN' | 'en-GB';
  voiceName?: string;
  rate?: number;  // 0.1 - 10, 預設 1
  pitch?: number; // 0 - 2, 預設 1
}

interface UseSpeechSynthesisReturn {
  // 狀態
  voices: SpeechSynthesisVoice[];
  isSpeaking: boolean;
  isPaused: boolean;
  isSupported: boolean;
  
  // 方法
  speak: (text: string, options: SpeechOptions) => Promise<void>;
  pause: () => void;
  resume: () => void;
  cancel: () => void;
  getVoicesForLanguage: (lang: string) => SpeechSynthesisVoice[];
}

export function useSpeechSynthesis(): UseSpeechSynthesisReturn {
  const [voices, setVoices] = useState<SpeechSynthesisVoice[]>([]);
  const [isSpeaking, setIsSpeaking] = useState(false);
  const [isPaused, setIsPaused] = useState(false);
  const synthRef = useRef<SpeechSynthesis | null>(null);
  
  const isSupported = typeof window !== 'undefined' && 'speechSynthesis' in window;
  
  useEffect(() => {
    if (!isSupported) return;
    
    synthRef.current = window.speechSynthesis;
    
    const loadVoices = () => {
      const availableVoices = synthRef.current?.getVoices() || [];
      setVoices(availableVoices);
    };
    
    loadVoices();
    synthRef.current.onvoiceschanged = loadVoices;
    
    return () => {
      synthRef.current?.cancel();
    };
  }, [isSupported]);
  
  const findBestVoice = useCallback((lang: string): SpeechSynthesisVoice | null => {
    if (lang === 'zh-HK') {
      // 粵語優先順序
      return voices.find(v => v.name === '善怡') ||
             voices.find(v => v.lang === 'yue-HK') ||
             voices.find(v => v.lang.includes('yue')) ||
             voices.find(v => v.lang.includes('HK')) ||
             null;
    } else if (lang === 'zh-CN') {
      // 普通話優先順序
      return voices.find(v => v.name === '婷婷') ||
             voices.find(v => v.lang === 'zh-CN') ||
             voices.find(v => v.lang.startsWith('zh') && 
                            !v.lang.includes('yue') && 
                            !v.lang.includes('TW')) ||
             null;
    } else {
      // 其他語言
      return voices.find(v => v.lang === lang) ||
             voices.find(v => v.lang.startsWith(lang.split('-')[0])) ||
             null;
    }
  }, [voices]);
  
  const speak = useCallback(async (
    text: string, 
    options: SpeechOptions
  ): Promise<void> => {
    if (!synthRef.current) {
      throw new Error('Speech synthesis not supported');
    }
    
    return new Promise((resolve, reject) => {
      // 取消之前的朗讀
      synthRef.current!.cancel();
      
      const utterance = new SpeechSynthesisUtterance(text);
      utterance.rate = options.rate ?? 0.9;
      utterance.pitch = options.pitch ?? 1;
      
      // 設定語音
      const voice = options.voiceName 
        ? voices.find(v => v.name === options.voiceName)
        : findBestVoice(options.lang);
      
      if (voice) {
        utterance.voice = voice;
        utterance.lang = voice.lang;
      } else {
        utterance.lang = options.lang;
      }
      
      utterance.onstart = () => setIsSpeaking(true);
      utterance.onend = () => {
        setIsSpeaking(false);
        resolve();
      };
      utterance.onerror = (event) => {
        setIsSpeaking(false);
        if (event.error !== 'interrupted' && event.error !== 'canceled') {
          reject(new Error(event.error));
        } else {
          resolve();
        }
      };
      
      synthRef.current!.speak(utterance);
    });
  }, [voices, findBestVoice]);
  
  const pause = useCallback(() => {
    synthRef.current?.pause();
    setIsPaused(true);
  }, []);
  
  const resume = useCallback(() => {
    synthRef.current?.resume();
    setIsPaused(false);
  }, []);
  
  const cancel = useCallback(() => {
    synthRef.current?.cancel();
    setIsSpeaking(false);
    setIsPaused(false);
  }, []);
  
  const getVoicesForLanguage = useCallback((lang: string) => {
    return voices.filter(voice => {
      const voiceLang = voice.lang.toLowerCase();
      if (lang === 'zh-HK') {
        return voiceLang.includes('yue') || voiceLang.includes('hk');
      } else if (lang === 'zh-CN') {
        return voiceLang === 'zh-cn' || 
               (voiceLang.startsWith('zh') && 
                !voiceLang.includes('yue') && 
                !voiceLang.includes('tw') &&
                !voiceLang.includes('hk'));
      } else {
        return voiceLang.startsWith(lang.split('-')[0].toLowerCase());
      }
    });
  }, [voices]);
  
  return {
    voices,
    isSpeaking,
    isPaused,
    isSupported,
    speak,
    pause,
    resume,
    cancel,
    getVoicesForLanguage,
  };
}
```

**儲存 API 抽象：**
```typescript
// services/platform/storage.ts
import { Preferences } from '@capacitor/preferences';

export const storage = {
  async get<T>(key: string): Promise<T | null> {
    if (isNative) {
      const { value } = await Preferences.get({ key });
      return value ? JSON.parse(value) : null;
    } else {
      const value = localStorage.getItem(key);
      return value ? JSON.parse(value) : null;
    }
  },
  
  async set(key: string, value: any): Promise<void> {
    const stringValue = JSON.stringify(value);
    if (isNative) {
      await Preferences.set({ key, value: stringValue });
    } else {
      localStorage.setItem(key, stringValue);
    }
  },
  
  async remove(key: string): Promise<void> {
    if (isNative) {
      await Preferences.remove({ key });
    } else {
      localStorage.removeItem(key);
    }
  },
};
```

**相機 API 抽象：**
```typescript
// services/platform/camera.ts
import { Camera, CameraResultType, CameraSource } from '@capacitor/camera';

export const camera = {
  async capture(): Promise<File | null> {
    if (isNative) {
      // 使用 Capacitor Camera 插件
      const photo = await Camera.getPhoto({
        quality: 90,
        allowEditing: false,
        resultType: CameraResultType.Uri,
        source: CameraSource.Camera,
      });
      
      // 轉換為 File 對象
      const response = await fetch(photo.webPath!);
      const blob = await response.blob();
      return new File([blob], 'photo.jpg', { type: 'image/jpeg' });
    } else {
      // 使用 Web getUserMedia
      return captureFromWebCamera();
    }
  },
  
  async pickFromGallery(): Promise<File | null> {
    if (isNative) {
      const photo = await Camera.getPhoto({
        quality: 90,
        allowEditing: false,
        resultType: CameraResultType.Uri,
        source: CameraSource.Photos,
      });
      
      const response = await fetch(photo.webPath!);
      const blob = await response.blob();
      return new File([blob], 'photo.jpg', { type: 'image/jpeg' });
    } else {
      // 使用 file input
      return pickFromFileInput();
    }
  },
};
```

### 13.4 OCR Mobile 優化建議

#### 13.4.1 方案比較

| 方案 | 速度 | 準確度 | 離線 | 實作難度 |
|------|------|--------|------|----------|
| Tesseract.js（現有） | 慢（3-5秒） | 85-90% | ✅ | 已完成 |
| ML Kit（Google） | 快（<1秒） | 95%+ | ✅ | 中 |
| Vision Framework（iOS） | 快（<1秒） | 95%+ | ✅ | 中 |

#### 13.4.2 建議策略

```
Phase 1（初期）：
  └── 繼續使用 Tesseract.js，驗證 App 可行性

Phase 2（優化）：
  └── 根據用戶反饋，評估是否需要原生 OCR
  
Phase 3（如需優化）：
  ├── iOS：使用 Vision Framework 插件
  └── Android：使用 ML Kit 插件
```

#### 13.4.3 原生 OCR 插件範例

```typescript
// services/platform/ocr.ts
import { isNative, platform } from './index';

export const ocr = {
  async recognize(imageFile: File, lang: string): Promise<string> {
    if (isNative && shouldUseNativeOCR()) {
      // 使用原生 OCR（需安裝對應插件）
      return recognizeWithNativeOCR(imageFile, lang);
    } else {
      // 使用 Tesseract.js
      return recognizeWithTesseract(imageFile, lang);
    }
  },
};

function shouldUseNativeOCR(): boolean {
  // 可根據設定或效能需求決定
  return platform === 'ios' || platform === 'android';
}
```
